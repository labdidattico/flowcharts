# Flowcharts

A browser-based editor of executable flowcharts for teaching introductory
programming: draw the diagram, run it step by step, watch the variables
update in real time.

**Try it live:** https://labdidattico.github.io/flowcharts/

## Features

- standard flowchart blocks: declarations, assignment, input/output, If,
  While / Do-While / For loops, comments, subroutine calls (double-bar
  predefined-process symbol)
- declaration groups compacted into a single block with a dedicated editor
- step-by-step execution with block highlighting, timed automatic run and a
  live variables table
- function tabs, undo/redo, autosave, save-as
- export to SVG, PNG and Mermaid
- pan and zoom preserved across edits
- works offline after the first visit (service worker)

The user interface is in Italian — the app is used in class with Italian
students.
